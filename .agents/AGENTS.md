# Agent Rules for Reading Journal

- When adding new quotes or observations to the reading journal, always append the author signature on the following line in the format: `> — Suyash Sahu, [Current Date]` (e.g., `> — Suyash Sahu, July 18, 2026`).
- Always arrange and insert new entries in chronological order based on the date of the entry.
- NEVER edit, rewrite, reorder, or remove any existing quotes, poems, thoughts, or writings under any circumstances. Always preserve existing text exactly as written by the user.
- For Hindi poems/writings, match the Hindi signature format: `— सुयश साहू<br>` followed by the date in Hindi (e.g. `27 जून, 2025`). For English writings, use `> — Suyash Sahu, [Current Date]`.
